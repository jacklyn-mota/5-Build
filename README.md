# Indie Film Collective

## Project Description

Indie Film Collective is a multi-page website for a fictional creative
community focused on independent filmmakers, storytellers, and visual
artists. The website provides information about film screenings,
filmmaking workshops, and opportunities for creative collaboration.

The site was created to practice building and organizing a multi-page
website using semantic HTML, CSS styling, responsive design, and
relative page navigation.

## Pages

- Home
- Film Screenings
- Workshops
- Collaborations
